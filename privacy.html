Privacy Policy for rclone-gdrive

rclone-gdrive is a private utility used by the account owner to connect personally controlled computers to the account owner's Google Drive using rclone.

Google user data accessed

The application may access Google Drive files and file metadata that the account owner authorizes through Google OAuth.

How Google user data is used

Google Drive data is used only to provide file access, mounting, synchronization, reading, writing, updating, and deletion requested by the account owner.

Storage

OAuth credentials, tokens, file metadata, and temporary file cache data may be stored locally on computers controlled by the account owner as required for rclone to operate.

Sharing and disclosure

Google user data is not sold, used for advertising, or shared with third parties except when necessary to provide the requested Google Drive functionality, to comply with applicable law, or to protect the security of the account and systems.

Artificial intelligence and machine learning

Google Workspace API data is not used to develop, improve, or train generalized or non-personalized artificial intelligence or machine learning models.

Data retention and deletion

Locally stored OAuth credentials, tokens, and cached data may be removed by the account owner at any time. Access may also be revoked through the Google Account security and connections settings.

Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions about this application or this privacy policy, contact the developer using the support email shown on the Google OAuth consent screen.
